🚀 Publikasi Perubahan

  1. Klik “Terapkan ke Pratinjau” — perubahan langsung terlihat di tab website (refresh halaman website).
  2. Klik “Unduh site-config.js” — file konfigurasi akan terunduh ke folder Downloads.
  3. Salin / pindahkan file hasil unduhan ke folder js\ di folder website, timpa file site-config.js yang lama.
  4. Jalankan PUBLISH.bat di folder website (klik dua kali) — perubahan terunggah ke GitHub dan Vercel otomatis meng-online-kan dalam 1–2 menit.

Jika website masih dibuka dari folder (belum online), langkah 4 dapat dilewati — cukup timpa file-nya.

Panel admin ini pengaman tingkat kenyamanan (password tersimpan di file konfigurasi). Pengaman sesungguhnya adalah akun GitHub Anda — hanya yang punya akses repo yang bisa mengubah website online.
